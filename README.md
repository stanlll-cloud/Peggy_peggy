# Ricoh GR Customizer

Customize your Ricoh GR IV with an easy-to-use Mac app with English and Traditional Chinese.

## Features

- English / 繁體中文 interface
- Import `.cube` LUTs and `.xmp` Look profiles
- Add custom Image Control presets and aspect ratios
- Customize power-off images
- Enable soft focus, date imprint, and B&W looks
- Halation for added preset slots, with highlight thresholds adapted to each preset

## Download

[Download for Mac — Intel & Apple silicon](downloads/Ricoh-GR-Customizer-0.7.3-en.4.zip?raw=true)

Unzip and open **01-USER-GUIDE-English.pdf** first. The guide and **00-START-HERE.txt** are beside the app.

Move **Ricoh GR Customizer.app** to Applications.

**Previously tested models:** Ricoh GR IV and Ricoh GR IV HDF (owner-reported testing of the earlier edition). The 0.7.3 update is a community beta; Mac launch and camera testing are pending.

Updates for this edition are provided through this repository's download link. In-app signed installation is not configured for this community edition. Its update destinations point only to this repository.

Based on [Maxwooow/Ricoh-GRMod](https://github.com/Maxwooow/Ricoh-GRMod). Original firmware-processing code retained. Not an official Ricoh product.
