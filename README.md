# GR Mod English

English-language community edition of [Maxwooow/Ricoh-GRMod](https://github.com/Maxwooow/Ricoh-GRMod), based on upstream 0.7.0 (commit `0d5c4494df6967e434eb73743814bbbb3bb1117d`).

## Download for Mac

Download [GRMod-English-0.7.0-en.1.zip](downloads/GRMod-English-0.7.0-en.1.zip?raw=true), extract it, and move **GR Mod English.app** to Applications. The ZIP also contains the complete corresponding source.

Supports Intel and Apple silicon. If macOS blocks the app, open **System Settings > Privacy & Security > Open Anyway**.

## Features

- Import `.cube` LUTs and `.xmp` Look profiles into Image Control.
- Add custom aspect ratios and power-off images.
- Access the upstream soft focus, date imprint, B&W looks, and custom preset-slot features.
- English interface, guides, and macOS permission messages on every system language.

The original layout and firmware-processing code are retained. No new camera features or store links were added.

## Status: Beta

The owner reports that this build opens on their Mac. UI production build and desktop backend tests passed. Full visual, card, camera, and Apple signature verification are still pending. See [VALIDATION.md](VALIDATION.md) for exact results and limitations. No Ricoh firmware is included.
